
E-Commerce Sales & Customer Analytics
Project Overview
This project focuses on analysing e-commerce sales performance and customer purchasing behaviour using Microsoft Excel. The dashboard provides insights into sales trends, product categories, customer demographics, and purchasing patterns to support data-driven business decisions.

Project Objectives
* Analyse overall sales performance and transaction trends.
* Identify top-performing product categories.
* Understand customer purchasing behaviour.
* Explore sales patterns across customer demographics and locations.
* Build an interactive dashboard to monitor key business metrics.

Tools & Technologies
* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Interactive Dashboard

Key Performance Indicators (KPIs)
* Total Sales: Overall revenue generated.
* Total Transactions: Number of recorded transactions.
* Total Quantity Sold: Total number of units sold.
* Average Order Value (AOV): Average sales value per transaction.

Analysis Performed
* Sales Performance Analysis: Evaluated overall sales and transaction performance.
* Product Category Analysis: Compared sales across product categories.
* Customer Demographics Analysis: Explored purchasing patterns by age and gender.
* Geographical Analysis: Examined sales across customer locations.
* Payment Method Analysis: Investigated customer payment preferences.
* Time-Based Analysis: Analysed sales trends over time.

* Helps identify high-performing product categories.
